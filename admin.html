Painel do portfólio

Gerencia os projetos e os contatos do site direto no GitHub. Tudo que você salvar aqui vira um commit no repositório e aparece no site em 1–2 minutos.

1. Conexão com o GitHub

Crie um token em github.com/settings/tokens → "Generate new token (fine-grained)" → dê acesso apenas ao repositório do portfólio, com permissão Contents: Read and write. O token fica salvo só neste navegador (localStorage), nunca é enviado a nenhum outro lugar além da API do GitHub.
